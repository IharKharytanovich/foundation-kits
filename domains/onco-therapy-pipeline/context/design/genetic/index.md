# Genetic Branch

Oncolytic virus (T-VEC approved, RP1/RP2 Phase 2–3, CG0070 Phase 3), CRISPR/base/prime (CTX110/BEAM-201 allogeneic CAR-T, >90% editing efficiency ex vivo), ASO/siRNA (siG12D-LODER 37.7–80.1× selectivity). Allele-specific targeting is real for *specific* drivers — KRAS G12C (covalent, infinite selectivity; sotorasib/adagrasib approved), KRAS G12D (~500× selectivity, Phase 1/2), fusion breakpoints, HPV E6/E7 — not "any mutation." Mostly ex vivo or organs you can reach (liver, NTLA-2001 >90% knockdown); direct in-vivo editing of solid-tumor cells is not clinically achieved (blocked by the delivery wall). The sequence-level guide/off-target oracle lives in the paired **onco-target-design** domain — point there for guide design.
