# End-to-End Personalized Onco-Therapy Pipeline — Knowledge Base

Your starting point for reasoning about the whole personalized oncolytic / CRISPR therapy process as one map: tumour-normal diff → target → guide → construct → delivery → bioreactor manufacturing → dose. The discipline throughout: **separate what you can compute from what is wet-lab engineering, and label every number's provenance.** A broad map is only useful if each node says how much to trust it.

Navigate by the parallel sweep (`exploreConcept` + `hybridSearch` + the folder `index.md`), not by walking folders one at a time. Do not guess filenames.

## Contents

- [pipeline/index.md](pipeline/index.md) — The stage-by-stage map and its dependencies: which stage feeds which, and where the whole loop's throughput is decided.
- [diagnosis-to-target/index.md](diagnosis-to-target/index.md) — The diff → target → guide front half (the deep work lives in the paired onco-target-design domain).

- [speed/index.md](speed/index.md) — The timeline reality versus the optimistic target, and which stages are actually compressible.
- [honesty/index.md](honesty/index.md) — The provenance discipline: which claims are computable, which are empirical, which are aspirational.
- [practice/index.md](practice/index.md) — Workflow, the kit-to-task map, and the interactive-scale boundary.
