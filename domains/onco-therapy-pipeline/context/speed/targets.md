# Speed Model Concepts

The [[stage-time-model]] sums per-stage times along the pipeline to estimate the [[end-to-end-timeline]]; it is the computable scaffold for reasoning about compressibility. The [[thirty-minute-target]] is named as an aspiration, checked against reality — it compresses stages that were never rate-limiting.
